# Word Chain – GitHub Pages

โครงสร้างพร้อมใช้งานบน GitHub Pages

```text
/
├── index.html
├── .nojekyll
└── data/
    ├── word-data.js
    └── gloss-data.js
```

## การทำงานของหน้าเริ่มต้น

เมื่อเปิดเกม ผู้เล่นจะเลือกก่อนว่า:

- **Single Player** → ไปยังหน้าเลือกโหมดเกมเดิม (ต่อคำ / มีตัวอักษรนี้)
- **Multiplayer** → แสดงสถานะว่าโหมดออนไลน์กำลังพัฒนา และยังไม่เปิดเกมออนไลน์

เมื่อพร้อมพัฒนา Multiplayer สามารถต่อระบบสร้างห้อง / เข้าห้องจากจุดนี้ได้โดยไม่ต้องรื้อ Single Player เดิม

## GitHub Pages

1. วางไฟล์ทั้งหมดใน root ของ branch `main`
2. ไปที่ **Settings → Pages**
3. เลือก **Deploy from a branch**
4. เลือก `main` และ `/ (root)`
5. Save แล้วรอ GitHub Pages deploy

อย่าลบโฟลเดอร์ `data/` เพราะ `index.html` โหลดฐานคำศัพท์และคำแปลจากโฟลเดอร์นี้


## Multiplayer UI prototype (Phase 1)

เวอร์ชันนี้เพิ่มหน้าสร้างห้อง/เข้าร่วมห้อง, รหัสห้อง, หน้าล็อบบี้, ปุ่มพร้อมแล้ว และปุ่มคัดลอกลิงก์เชิญ โดยยังเป็น UI prototype ที่ทำงานภายในเบราว์เซอร์เท่านั้น

**ยังไม่ใช่ระบบออนไลน์จริง:** รหัสห้องและรายชื่อผู้เล่นยังไม่ถูกบันทึก/ซิงก์ระหว่างอุปกรณ์ การเล่นข้ามเครื่องและสถานะเรียลไทม์ต้องตั้งค่า Supabase (Database + Realtime + RLS) และเชื่อมต่อ frontend ก่อน ห้ามใส่ service-role key ไว้ในหน้าเว็บ
